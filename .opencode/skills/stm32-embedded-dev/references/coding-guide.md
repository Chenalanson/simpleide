## 1. 技术栈判定

阶段 0 先确认，未确认时按默认推进并标注：

| 维度 | 选项 | 默认与处理 |
|---|---|---|
| 固件库 | HAL（默认主线）/ LL / 标准库 SPL | 默认 HAL；用户指定后切换风格（LL 偏寄存器封装、SPL 偏 `GPIO_Init` 结构体，映射思路一致） |
| 系统 | 裸机主循环 + 状态机（默认）/ FreeRTOS | 用户提任务、队列、调度再启用第 13 节 |
| 工程形式 | 新建模块 / 现有工程续写 | 现有工程优先走第 14 节最小改动流程 |

代码骨架以下以 HAL 为主线；切换库类型时调整函数名与结构体字段，结构分层不变。

## 2. 代码与台账的同源关系

台账是硬件配置的单一事实来源，代码只做落地与逻辑，不另造一套参数：

| 台账字段（hardware.dts） | 代码落地位置 |
|---|---|
| `compatible` / 实例 label（`uart2`） | 句柄名（`huart2`）、模块前缀（`uart2_xxx`） |
| `current-speed = <115200>` | `huart2.Init.BaudRate = 115200;` |
| 引脚组 `uart2_tx_pa2`（pin/af） | GPIO 初始化结构体端口、引脚、复用号（AF 值待核对处传宏 + TODO 注释） |
| 通道子节点 `ch_vin: channel@2` | ADC 通道枚举/宏 `ADC_CHANNEL_2`、通道编号数组顺序一致 |
| `frequency-hz = <20000>`（PWM） | PSC/ARR 复算后填入（复算公式见 checklist.md） |
| `dmas` / `dma-names` | DMA 句柄与通道配置、外设 `HAL_xxx_Init` 关联 |
| `interrupts = <IRQn pri>` | NVIC 使能与优先级；ISR 函数名与启动文件向量一致 |
| 外部器件地址 `reg = <0x48>` | 总线读写地址参数 |

规则：台账标注「待核对」的数值，代码中用集中定义的宏承载（如 `#define UART2_TX_AF  7u /* TODO: 对照 RM 复用表核对 */`），不把未核实常量散落在函数体内。

## 3. 分层结构与文件划分

```
App/
├── bsp/                  # 板级配置层：外设初始化（对照台账逐实例生成）
│   ├── bsp_uart.c/.h
│   ├── bsp_adc.c/.h
│   └── bsp_pwm.c/.h
├── drivers/              # 驱动接口层：模块通用操作（寄存器无关的封装）
│   ├── sensor_xxx.c/.h
│   └── bus_proto.c/.h
├── app/                  # 业务逻辑层：状态机、协议解析、控制策略
│   ├── app_main.c
│   └── app_fsm.c
└── bsp_conf.h            # 集中宏定义：引脚/通道/缓冲长度/超时常量（与台账对应）
```

- **配置层**：`MX_xxx_Init` 风格初始化；若工程已有 CubeMX 生成初始化，不重写，只补充用户层回调与业务模块。
- **驱动层**：对外暴露简洁接口（打开/读取/写入/启停），错误用状态码返回，不依赖具体上层。
- **业务层**：不直接操作外设句柄细节，通过驱动层接口交互；状态机用 `switch-case` 或函数指针表。
- 句柄归属：CubeMX 工程中句柄多在 `main.c`/`xxx.c` 定义，跨模块用 `extern` 声明于对应 `.h`，禁止重复定义。

## 4. 通用编码规范

1. **命名**：模块前缀 + 动作，如 `adc1_read_vin_mv()`、`uart2_send_block()`；静态函数加 `static`；宏全大写下划线分隔。
2. **错误处理**：HAL 调用检查 `HAL_OK`；自定义模块用枚举错误码；等待类接口带 `timeout_ms` 参数，超时返回错误，禁止裸 `while(1)` 死等。
3. **参数宏化**：波特率、缓冲长度、超时、通道序号、滤波窗口一律 `#define`；禁止函数体内魔法数字。
4. **注释**：文件头说明模块职责与对应台账节点；函数注释含功能、参数、返回值、被调用位置；待核对处 `/* TODO: 手册核对点 */`。
5. **常量入 Flash**：查表、协议常量字串加 `const`；全局共享缓冲在中断/主循环间共享时加 `volatile`。
6. **边界安全**：数组下标有长度判断；`snprintf` 替代 `sprintf`；指针解引用前判空。

## 5. GPIO 要点

- 初始化结构体字段：Mode / Pull / Speed / Alternate；模拟量输入配 `Analog` 模式；复用功能配 `AF` 模式。
- 输出类（LED、使能脚）提供 `set(on/off)` 封装，内部处理有效电平（`active-low` 取反逻辑集中在一层）。
- 输入中断类：EXTI 触发沿（上升/下降/双边）与台账 `trigger` 一致；回调 `HAL_GPIO_EXTI_Callback` 内先判引脚再分支，仅置标志/提交任务，不做长逻辑。
- 未使用引脚：按台账 `disabled` 建议配置为模拟输入或下拉，不悬空。

## 6. USART（轮询 / 中断 / DMA 不定长接收）

### 6.1 选型

| 场景 | 实现 | 要点 |
|---|---|---|
| 低频日志、命令 | 轮询发送 `HAL_UART_Transmit` | 发送超时退出；不在中断内调用 |
| 简单定长接收 | `HAL_UART_Receive_IT` | 回调内重新启动接收；状态机解析 |
| 不定长帧、高吞吐 | DMA 循环 + 空闲中断 | `HAL_UARTEx_ReceiveToIdle_DMA`；`RxEvent` 回调取长度并写入环形缓冲 |

### 6.2 骨架约束

- 接收环形缓冲：`head/tail` 索引 + 长度判断；解析状态机在主循环/任务中运行，回调只搬运。
- 协议帧：帧头、长度、校验（CRC/和校验）；残帧与越界索引丢弃处理。
- 波特率复算依据 checklist.md；`fPCLK` 与工程实际时钟一致，时钟变更后复算。
- 中断优先级与 DMA 协调；避免日志打印阻塞关键循环。

## 7. ADC（轮询 / 规则组扫描 DMA）

- 多通道：通道初始化顺序与 DMA 数组下标顺序严格一致（对应台账 `ch_xxx` label 列表顺序）。
- 轮询单次：`HAL_ADC_Start` → `PollForConversion` → 读数 → 停止；低频采集适用。
- 扫描 DMA 循环：启动后在传输完成/半完成回调中更新数据指针；数组类型与分辨率匹配（12 位用 `uint16_t`）。
- 换算：原始值 → 毫伏/工程量使用 `VREF` 与增益公式；系数集中宏定义，与台账 `reference`、分压比对应。
- 采样时间：源阻抗高时加大采样周期；上电必要时执行校准流程（带自校准系列）。
- 电机电流采样：硬件偏置与增益先保证，软件滤波（滑动平均/中值）标注延迟；同步触发需求在台账备注，代码不臆造触发配置。

## 8. 定时器：定时中断 / PWM 输出

### 8.1 频率复算（代码填值前必算）

```
更新频率 f = fTIMCLK / ((PSC+1) × (ARR+1))
边沿对齐 PWM 频率同上；占空比 = CCR / (ARR+1)（向上计数）
APB 预分频 ≠ 1 时 fTIMCLK = 2 × PCLK（以 RM 时钟树为准）
```

### 8.2 要点

- 定时中断：`HAL_TIM_PeriodElapsedCallback` 先判 `htim->Instance` 再分支；回调内置标志或提交 `k_work`/消息，不跑长逻辑。
- PWM：`HAL_TIM_PWM_Start` 对应通道；运行期调 `__HAL_TIM_SET_COMPARE` 更新占空比，避免反复重配初始化。
- 高级定时器（TIM1/TIM8）：主输出使能（MOE）、刹车极性、死区时间为安全项；台账 `brake_bkin`/`safe-state` 必须在代码初始化与故障处理中落地；故障动作 = 停 PWM + 关使能。
- 输入捕获：测频用两次上升沿差值 + 溢出计数；测脉宽用双边沿；单位换算集中函数。

## 9. SPI

- 主模式全双工；配置含方向、数据宽度、CPOL/CPHA（与从机手册一致，对应台账字段）、波特率分频。
- 片选优先软件 GPIO 管理：拉低 → 收发 → 拉高；每次传输检查 HAL 返回与错误标志。
- 大批量传输评估 DMA；`spi_transceive` 类封装带超时；收发缓冲长度对齐。
- 易错：CPOL/CPHA 配反导致数据错位；片选保持时间不足；时钟超从机上限。

## 10. I2C

- 速率档位（100k/400k）与台账 `clock-frequency-hz` 一致；上拉与总线电容属硬件，代码不替代。
- 器件寄存器读写封装：`dev_read_reg(dev_addr, reg, buf, len)` / `dev_write_reg(...)`；地址用 7bit（库函数内部处理 R/W 位，按所用库版本约定核对）。
- 错误处理：超时返回错误码；总线忙/仲裁丢失状态有重试或上报；不无限等待。
- 传感器初始化序列按器件手册上电时序实现，延时长度与台账备注一致。

## 11. CAN / FDCAN

- 位时序（波特率、采样点）与台账一致；过滤器配置（标准/扩展 ID、列表/掩码模式）按接收需求。
- 发送带超时；接收回调或接收线程解析帧；帧 ID 与 DLC 校验。
- 硬件层（收发器、终端电阻、共地）不在代码职责内，台账已记录要求；代码只保证协议收发与错误状态上报。

## 12. DMA 通用约束

- 方向：外设→内存（ADC/RX）、内存→外设（TX/DAC）；内存地址递增、外设地址固定。
- 宽度匹配：外设数据宽度与数组元素类型一致（字节流 `uint8_t`、ADC `uint16_t`）。
- 模式：循环模式适合连续采集；单次模式传完需重启；缓冲区长度 ≥ 单次最大数据量。
- 通道/请求号以台账 TODO 核对结果填入；多通道按实时性排优先级。
- 全局 DMA 缓冲加 `volatile`；传输完成标志的清除时机正确。

## 13. FreeRTOS 可选层

### 13.1 机制选择

| 需求 | 机制 | 要点 |
|---|---|---|
| 周期任务节拍 | 任务内 `vTaskDelayUntil` | 相位稳定，优于 `vTaskDelay` |
| ISR/回调 → 任务 | 队列 `xQueueSendFromISR` / 任务通知 / 信号量 | ISR 仅用 `FromISR` API，末尾 `portYIELD_FROM_ISR` |
| 共享资源互斥 | 互斥量 `xSemaphoreCreateMutex` | 带优先级反转保护；临界区不含阻塞调用 |
| 多事件位 | 事件组 `xEventGroup` | 位掩码等待与清除 |

### 13.2 约束

- 栈大小 = 局部变量峰值 + 调用链深度 + 异常压栈余量，首次 1.5~2 倍余量，上线后用水位（`uxTaskGetStackHighWaterMark`）校准。
- 优先级数值越大优先级越高；中断优先级数值越小越高，越界中断禁止调 API（对照 `configMAX_SYSCALL_INTERRUPT_PRIORITY`）。
- 任务内禁止阻塞式外设轮询长等待；队列满、获取失败要有兜底处理。
- 开启栈溢出钩子辅助定位；静态/动态栈分配方式与工程配置一致。

## 14. 现有工程最小改动规则（用户既定偏好，强制）

1. **先通读后动笔**：通读现有初始化、句柄定义、模块命名、头文件包含关系，列出现有可复用项。
2. **只追加不重写**：
   - 新功能代码归入新 `.c/.h` 或现有模块末尾追加函数；
   - 不修改 CubeMX 生成的 `MX_xxx_Init` 内容；
   - 不重构已有函数签名、不改动已验证的引脚/时钟配置。
3. **插入点显式标注**：每个新增片段给出文件路径与插入位置（如「`bsp_adc.c` 末尾追加」「`main()` 初始化序列 `MX_ADC1_Init()` 之后调用 `app_sensor_init()`」）。
4. **修改点说明**：若必须改现有行，逐条列出「文件 + 位置 + 原值 + 新值 + 原因」；能通过新增封装规避修改的，优先新增。
5. **复用优先**：现有句柄、宏定义、公共延迟/打印函数直接引用，不重复定义同义设施。
6. **台账对齐**：在现有工程补功能时，先把新资源登记进台账，再写代码；代码与台账互相印证。
