## 1. 排查总则与顺序

1. 编译期 → 链接期 → 运行期；时钟/映射 → 使能初始化 → 参数值 → 业务逻辑。
2. 记录四要素：现象、复现步骤、相关代码文件/台账节点、观测值（寄存器/波形/日志）。
3. 一次只改一个变量；外设初始化改动后完整重编下载。
4. 硬件问题（接线、电平、晶振、终端电阻、共地）优先用万用表/逻辑分析仪确认；无仪器时用回环、GPIO 翻转、LED 指示做粗判，并 `pending_ask(kind=observe)` 说明所需设备，不得把未测量写成已确认。
5. 台账 TODO 未销项的配置点为优先怀疑对象（见第 6 节 D 步骤）。

## 2. 编译错误表（C-x）

| 编号 | 报错特征 | 原因 | 最小处理 |
|---|---|---|---|
| C1 | `unknown type name` / 未声明标识符 | 头文件缺失；声明顺序错；外设未使能致句柄未生成 | 补 `#include`；调顺序；确认驱动参与编译 |
| C2 | `expected ';' before ...` | 中文标点；宏尾缺分号；括号不配对 | 按行号修标点与配对 |
| C3 | 类型不匹配（指针/枚举/整型混用） | 返回值未接收；签名与调用不一致 | 统一类型，规范接返回值 |
| C4 | `implicit declaration of function` | 函数未在 `.h` 声明；参数列表不一致 | 补声明并核对参数 |
| C5 | `redefinition / multiple definition` | 变量在头文件直接定义且多处包含；句柄重复 | 定义收敛到单 `.c`，头文件 `extern`；查保护宏 |
| C6 | 宏未定义（如 `ADC_CHANNEL_2`） | 外设驱动头未引入；组件未勾选 | 确认 `stm32xxx_hal_xxx.h` 在构建列表 |
| C7 | 库版本 API 找不到 | 当前库版本低于 API 引入版本 | 降级写法或升级库，给兼容替代 |
| C8 | 编码乱码警告 | 文件编码不一致（GBK/UTF-8/BOM） | 统一 UTF-8；Windows 保存注意无 BOM |

## 3. 链接错误表（L-x）

| 编号 | 报错特征 | 原因 | 最小处理 |
|---|---|---|---|
| L1 | `undefined reference to xxx` | 源文件未入构建；名称拼写/大小写错；库未链接（如 CMSIS-DSP） | 查工程源文件列表与库依赖 |
| L2 | `multiple definition of xxx` | 同名定义多处；头文件直接定义变量 | 唯一定义；头文件 `extern` 声明 |
| L3 | `region FLASH/RAM exceeded` | 容量超限；缓冲/栈/堆过大 | 查 Map 文件；常量入 `const`；裁剪缓冲与栈 |
| L4 | ISR 向量名不符 | 函数名拼错（`USART1_IRQHandler` ↔ `USART1_IRQn`） | 对照 `startup_*.s` 弱符号表逐字核对 |
| L5 | `__initial_sp` / 栈顶符号缺失 | 链接/分散加载配置缺失 | 检查链接脚本 `MEMORY` 与栈导出符号 |

## 4. HardFault 定位流程（H-x）

| 步骤 | 动作 |
|---|---|
| H1 采集现场 | 有探针：调试器暂停，读 `PC/LR/SP`、`SCB->CFSR/HFSR`、`MMFAR/BFAR`；无探针：读 LED 故障码/GPIO 状态/CLI `diag reg` 转储（若 CLI 可用），仍无法取得则 `pending_ask(kind=observe)`，禁止臆测寄存器 |
| H2 回溯栈帧 | Cortex-M 压栈顺序 `R0,R1,R2,R3,R12,LR,PC,xPSR`；由 SP 读出 PC 即出错指令位置 |
| H3 按 CFSR 位定位成因（下表） | 命中位 → 成因类别 → H4 对应分支排查 |
| H4-a 栈溢出 | 查 Map 栈区 + RTOS 栈水位；局部大数组/深调用链 |
| H4-b 空/野指针 | 句柄、函数指针、回调表、`malloc` 返回值判空；结构体成员初始化 |
| H4-c 外设访问顺序 | 时钟先使能再访问寄存器；DMA 缓冲地址与宽度合法 |
| H4-d 上下文错误 | ISR 调非 `FromISR` API；RTOS 优先级越界；任务返回未删 |
| H4-e FPU | FPU 使能与编译 `-mfloat-abi` 一致 |
| H5 对照修复 | 出错 PC 反汇编对源码定位触发行；禁止以屏蔽异常替代根因修复 |

CFSR 位速查：

| 位 | 含义 | 典型成因 |
|---|---|---|
| IACCVIOL | 指令访问违例 | 函数指针野值；跳转地址非法；Thumb 位缺失 |
| DACCVIOL | 数据访问违例 | 空/野指针；访问未使能外设；数组越界写 |
| IBUSERR/PRECISERR/IMPRECISERR | 总线错误 | DMA 越界；时钟未开即访问；写只读位 |
| UNDEFINSTR | 未定义指令 | 栈踩坏；调用栈失衡 |
| INVSTATE | 非 Thumb 态 | 函数指针地址为偶数；链接异常 |
| NOCP | 协处理器非法访问 | FPU 未使能却跑浮点指令 |
| STKERR/UNSTKERR | 压栈/出栈错误 | 栈溢出，SP 越界 |

## 5. 运行现象排查链（P-x）

### 5.1 串口无输出 / 乱码（P-UART）

1. P-U1 接线：TX/RX 交叉、共地、电平匹配（3.3V TTL vs RS232）。
2. P-U2 时钟：`fPCLK` 与波特率复算一致；HSE 未起振回退 HSI 会产生频偏。
3. P-U3 引脚：模式与复用号对齐台账；调试脚无冲突。
4. P-U4 代码：初始化返回值；发送启动；回调重启接收；打印重定向未被优化。
5. P-U5 乱码优先查波特率不匹配，其次校验位/停止位一致、线缆干扰与共地。

### 5.2 DMA 不触发 / 数据不动（P-DMA）

1. P-D1 外设 DMA 请求使能位（如 ADC continuous、UART DMAR）。
2. P-D2 DMA 映射：F1 为固定通道映射；F4/G4/H7 等经 DMAMUX 选 request（查 RM，对照台账 TODO）。
3. P-D3 缓冲指针、宽度、长度；启动函数是否调用。
4. P-D4 DMA NVIC 使能与标志清除时机；DMA 控制器时钟使能。

### 5.3 ADC 数据异常（零值/满幅/跳变/漂移，P-ADC）

1. P-A1 通道号-引脚映射；引脚模式为模拟。
2. P-A2 参考源与采样时间（源阻抗高→加大采样周期）；基准稳定性。
3. P-A3 DMA 数组顺序 = Rank 顺序；类型宽度匹配；缓冲 `volatile`。
4. P-A4 校准流程；输入超范围；滤波窗口过大导致滞后。
5. P-A5 电流采样先查模拟前端（偏置/增益/滤波），再查软件换算。

### 5.4 PWM 无波形 / 占空比不变化（P-PWM）

1. P-P1 定时器时钟与分频复算；`ARR ≥ CCR`。
2. P-P2 引脚复用模式与 AF；`PWM_Start` 已调用。
3. P-P3 TIM1/TIM8（高级定时器）MOE 主输出使能；通用/基本定时器没有 MOE。
4. P-P4 刹车输入是否有效电平；死区是否过长。
5. P-P5 波形测量：示波器接地弹簧短接实测，排除探头引线误判；无示波器时用逻辑分析仪/GPIO 翻转/LED 占空比粗判，仍无手段则 `pending_ask(kind=observe)`。

### 5.5 SPI / I2C 通信失败（P-BUS）

1. P-B1 接线、上拉（I2C）、片选、供电电平。
2. P-B2 CPOL/CPHA、速率上限、器件 7bit 地址。
3. P-B3 超时处理与重试；总线锁死恢复；上电时序。
4. P-B4 从器件复位/使能状态。

### 5.6 中断进不去 / 反复进入（P-IRQ）

1. P-I1 NVIC 使能与优先级分组；外设中断使能位。
2. P-I2 ISR 函数名对齐启动向量；回调重启接收。
3. P-I3 标志清除时机正确（先清标志再退出）。
4. P-I4 RTOS 调用 API 的中断优先级不越界。

### 5.7 RTOS 异常（P-RTOS）

1. P-R1 栈溢出：开 `configCHECK_FOR_STACK_OVERFLOW` 钩子；水位反推。
2. P-R2 死锁：互斥量获取顺序；ISR 不调阻塞 API；队列满兜底。
3. P-R3 任务不运行：未让出 CPU（无延时/阻塞）；栈为 0；优先级配置。
4. P-R4 周期抖动：任务执行时间接近周期时先缩短周期验证。

### 5.8 电机/功率安全故障（P-PWR，仅软件侧辅助定位）

1. P-W1 过流：先查采样硬件链路，再查软件阈值与采样同步点。
2. P-W2 桥臂直通：死区、互补逻辑、刹车响应、栅极驱动回路。
3. P-W3 环路振荡：先处理模拟补偿与采样滤波，增益按阶跃响应逐步整定。

## 6. 台账联动核对法（D-x，每次排查先执行）

| 步骤 | 动作 | 输出 |
|---|---|---|
| D1 定位节点 | 打开台账对应实例节点，核对 `usage`、引脚、参数、TODO 项 | 台账摘录 |
| D2 三列对照 | 列「台账记录值 / 代码实际值 / 实测值」三列，标注不一致处 | 差异表（引用模板 D §4.1 改动表） |
| D3 TODO 优先 | 台账未销项的 AF/IRQn/DMA 映射优先验证 | 待核实行清单 |
| D4 变更回溯 | 确认台账未落后于原理图/接线；先更台账再改代码 | 台账更新片段（仅采用模板 E §2 的 dts 片段格式；T4 输出仍用模板 D，不切模板 E） |
| D5 冲突反查 | 交叉检查引脚占用表、EXTI 线号、DMA 通道是否冲突 | 冲突项与替代建议 |

## 7. 观测手段清单

| 手段 | 用途 |
|---|---|
| 调试器 | 断点、监视窗、外设寄存器视图（SVD）、反汇编对照 PC |
| 逻辑分析仪 | UART/SPI/I2C/CAN 协议解码与时序 |
| 示波器 | PWM、ADC 输入、电流纹波、栅极波形 |
| Map / `.list` 文件 | RAM/Flash 占用大户；函数占用反查 |
| 软件观测 | 状态枚举化、错误码落变量、复位原因（RCC_CSR）记录、最小系统法逐外设验证 |
| 无仪器/无串口 | `pending_ask(kind=observe)`，说明所需设备与替代方案；不得把未观测项标为通过 |
