## 1. 常见功能需求映射表（台账节点 + 代码落点）

| 用户描述的需求 | 台账中建立的内容 | 关键字段/节点 | 代码落点（coding-guide.md） |
|---|---|---|---|
| 调试串口 / 日志输出 | uart 实例 + 两个引脚组 + 绑定视图 | `current-speed`、`pinctrl-0`、`app-bindings.console` | 第 6 节 USART 轮询发送；配置层初始化 + 打印封装 |
| 上位机不定长命令收发 | uart 实例 + DMA tx/rx 预留 + 帧格式备注 | `dmas`/`dma-names`、`note`（帧格式） | 第 6.2 节 DMA 循环 + 空闲中断；环形缓冲 + 状态机放业务层 |
| 单路电压/温度采集 | adc 控制器 + `channel@N` 子节点 + 绑定视图 | `reg`、`reference`、`acquisition-time`、`usage` | 第 7 节 ADC 轮询单次；换算函数放驱动层 |
| 多路周期采集（电压/电流/温度） | adc 控制器 + 多通道子节点 + 节拍备注 | 通道 label 列表、采样节拍 `note` | 第 7 节扫描 DMA；数组顺序与通道顺序一致；业务层滤波 |
| 电机 PWM 输出（单路/三相） | timers 实例 + 通道子节点 + 刹车/使能安全节点 | `frequency-hz`、`complementary`、`brake_bkin`、`en_power`、`safe-state` | 第 8 节 PWM；第 5 节 GPIO 安全脚；故障动作链放业务层 |
| 相电流采样 | adc 通道备注同步触发需求；标注相别 | `note`「与 PWM 同步」、`usage` 相别 | 第 7 节采样 + 第 13 节任务节拍配合；换算系数集中宏定义 |
| I2C 传感器（温湿度/气压/EEPROM） | i2c 总线节点 + 器件子节点（地址、型号） | `clock-frequency-hz`、`reg = <7bit地址>`、`chip` | 第 10 节 I2C 寄存器读写封装；驱动层器件接口 |
| SPI Flash / 显示屏 | spi 总线节点 + 器件子节点（片选、频率、模式） | `frequency-hz`、`cpol/cpha`、`cs-pin`、`max-frequency-hz` | 第 9 节 SPI 收发封装；片选管理在驱动层 |
| CAN 总线通信 | can 实例 + 引脚组 + 网络参数 | `bus-speed-bps`、`sample-point-permille`、终端电阻备注 | 第 11 节 CAN 发送/过滤器/接收回调 |
| 按键 / LED / 状态指示 | gpio 节点（方向、有效电平、触发） | `io-direction`、`polarity`、`pull`、`trigger` | 第 5 节 GPIO；有效电平取反逻辑集中在一层 |
| 外部中断（故障信号、限位） | gpio 节点 + 中断优先级建议备注 | `trigger`、`note` | 第 5 节 EXTI 回调；回调内置标志/提交任务，不写长逻辑 |
| 看门狗保护 | 独立安全节点（IWDG/WWDG 规划） | `usage`、喂狗窗口 `note` | 业务层周期喂狗；主循环/任务中检查窗口约束 |
| 低功耗产品 | 未用脚处理备注 + 时钟备注 + 唤醒脚预留 | `note`、`status="disabled"`、唤醒脚节点 | 配置层引脚处理；业务层低功耗进入/退出点预留 |
| 外部器件复位/电源使能 | gpio 节点 + 上电时序备注 | `polarity`、时序 `note` | 驱动层初始化序列按手册延时调用 |
| 预留扩展 | `status = "disabled"` 备用引脚节点 | `usage`、`pin` | 暂不生成代码；台账保留以备后续启用 |

## 2. 参数计算依据（填写台账数值前复算）

### 2.1 串口波特率

```
过采样 16：USARTDIV = fPCLK / (16 × BaudRate)
过采样 8 ：USARTDIV = fPCLK / (8 × BaudRate)
验收：实际波特率与目标误差按 DS 限值（常见 ≤ ±2%）；fPCLK 取时钟规划实际值
台账记录：current-speed = <目标波特率>；note 记录所用 fPCLK 与误差结论
```

### 2.2 PWM / 定时器频率

```
边沿对齐：fPWM = fTIMCLK / ((PSC+1) × (ARR+1))
占空比范围：0 ≤ CCR ≤ ARR；占空比 = CCR / (ARR+1)
注意：APB 预分频 ≠ 1 时 fTIMCLK = 2 × PCLK（以 RM 时钟树为准）
台账记录：frequency-hz = <目标频率>；不记录 PSC/ARR 具体值（那是后续代码/配置细节），
          仅在 note 标注「定时器时钟倍频关系需复算」
```

### 2.3 ADC 转换时间与采样率

```
Tconv = 采样时间(cycles) + 转换时间(cycles，12 位常见 12.5 周期，以 DS 为准)
单通道最高采样率 ≈ fADC_max / Tconv
多通道周期节拍 ≥ 通道数 × Tconv + 软件处理余量
台账记录：resolution、reference、acquisition-time 备注；note 记录目标采样节拍
```

### 2.4 总线速率

```
I2C：standard 100kHz / fast 400kHz / fast-plus 1MHz；速率受上拉电阻与总线电容限制
SPI：SCLK ≤ 从机手册最大频率；CPOL/CPHA 四模式以从机手册时序图为准
CAN：位速率 × 采样点位置全总线一致；位段（同步段+传播段+相位段1+相位段2）和为 1 位时间
台账记录：总线频率/速率字段 + note 记录对端约束与匹配要求
```

### 2.5 资源预算估算

- 引脚占用：已用引脚数 ≤ 封装可用 GPIO 数（DS 封装表）；预留 10%~20% 扩展余量。
- DMA：通道数对照 DMA 控制器通道总数；多外设共用时按实时性排序。
- 中断：外部中断线（EXTI0~15 等）按线号分组，同一线号不可分给两个不同触发源。
- RAM/Flash：台账阶段只做定性提示（缓冲、查表、协议栈占用量级），不做精确代码统计。

## 3. 规划易错点清单（按外设分组）

### 3.1 时钟与系统

- 把 HSI 当精确时钟源用于通信（HSI 精度有限，串口/CAN 建议 HSE）。
- 忽略 APB 倍频导致定时器频率算错；台账时钟规划必须列出各总线频率。
- 主频超过 DS 额定上限；低功耗场景未备注降频路径。

### 3.2 引脚与复用

- AF 号凭记忆填写（最高频错误）；台账一律 TODO 占位，查 RM 复用表后销项。
- ADC 通道号与物理引脚错位（同一通道在不同封装可能映射不同引脚）；对照 DS「ADC 通道-引脚」表。
- I2C 引脚未备注外部上拉要求；SPI 片选脚漏建节点。
- 未用管脚悬空（噪声、功耗、误触发）；台账用 `status="disabled"` + note 记录推荐处理（模拟输入/上下拉）。
- 同一引脚被两个实例同时引用（台账阶段即可发现并提示冲突）。

### 3.3 串口/总线

- 波特率与 fPCLK 不匹配导致误差超标；台账记录复算结论。
- I2C 地址误写 8bit（含 R/W 位）；台账 `reg` 统一 7bit。
- CAN 只记速率不记采样点；漏记终端电阻与收发器型号要求。
- SPI CPOL/CPHA 与从机手册不符；台账字段显式记录四个组合选择。

### 3.4 ADC

- 参考源选错（内部 VREFINT 精度有限，高精度测量需外部基准）。
- 高源阻抗信号配过短采样时间导致读数偏低/跳动；`acquisition-time` 必须备注依据。
- 电流采样通道漏记偏置与增益换算说明（台账 `usage`/`note` 承载换算系数来源）。

### 3.5 PWM 与安全资源（电机/功率场景重点）

- 只建 PWM 通道节点，漏建刹车（BKIN）与使能（EN）安全节点。
- 未记录互补输出、死区时间、故障关断动作要求；安全节点必须带 `safe-state` 与故障动作注释。
- 复位默认电平可能误导功率级（上电瞬间导通）；`en_power` 节点备注默认关断要求。
- 频率选在电机/电源谐振或噪声敏感频段未做备注。

### 3.6 DMA 与中断

- DMA 通道/请求号映射随系列变化（部分系列有 DMAMUX 可重映射）；台账只写建议并标 TODO。
- 中断优先级未分组规划；台账 `interrupts` 记录建议优先级并 note 说明分组方案。
- 把慢任务挂在高优先级中断资源上；规划阶段在 note 标注「建议任务化处理」。

### 3.7 台账工程性问题

- 命名不统一（`uart2`/`usart2`/`serial1` 混用）；按 `ledger-schema.md` 第 4 节规范统一。
- `app-bindings` 引用了不存在的节点（引用不闭合）；生成后逐条核对。
- 待核对项散落在全文、无汇总；必须在文件末尾汇总块集中管理。
- 方案变更只改口头描述不改台账，导致台账与原理图脱节；在使用说明中强调「先改台账」。
