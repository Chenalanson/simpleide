## 1. 排查总原则（先台账后代码）

1. 先编译期、后运行期；先「台账记录 ↔ 代码实现」一致性，再业务逻辑；先最小复现，再整体联调。
2. 记录现象：复现步骤、相关代码段、台账对应节点、观测值（波形/日志/寄存器）、芯片型号与库版本。
3. 一次只改一个变量；外设初始化改动后重新完整编译下载。
4. 硬件问题（接线、电平、电源、晶振、终端电阻）先用万用表/逻辑分析仪确认，不只在软件里找原因。
5. 台账 TODO 未销项的配置点，是运行异常的优先怀疑对象。

## 2. 编译错误速查

| 报错特征 | 常见原因 | 处理方向 |
|---|---|---|
| `unknown type name` / 未声明标识符 | 头文件缺失；类型定义顺序错误；外设未使能导致句柄未生成 | 补 `#include`；调整声明顺序；确认工程外设驱动参与编译 |
| `expected ';' before ...` | 中文标点、宏尾缺分号、括号不配对 | 按行号修标点与配对 |
| 类型不匹配（指针/枚举/整型混用） | HAL 返回值未接收；函数签名与调用不一致 | 统一返回类型，按规范接返回值 |
| `implicit declaration of function` | 函数未在 `.h` 声明；参数列表不一致 | 补声明；核对参数 |
| `redefinition / multiple definition` | 变量在头文件直接定义且多处包含；句柄重复定义 | 定义收敛到单个 `.c`，头文件 `extern` 声明；检查头文件保护宏 |
| 宏未定义（如 `ADC_CHANNEL_2`） | 对应外设驱动头未引入；库组件未勾选 | 确认 `stm32xxx_hal_xxx.h` 参与编译 |
| 库版本 API 找不到 | 当前库版本低于所用 API 引入版本 | 降级用法或升级库；给出兼容写法 |
| 编码/乱码警告 | 文件非 UTF-8 或 BOM 问题 | 统一编码；Windows 保存注意无 BOM |

## 3. 链接错误速查

| 报错特征 | 常见原因 | 处理方向 |
|---|---|---|
| `undefined reference to xxx` | 源文件未加入构建；函数名拼写/大小写错；库未链接（如 CMSIS-DSP） | 检查工程源文件列表与库依赖 |
| `multiple definition of xxx` | 同名变量/函数多处定义 | 定义唯一化；公共声明放头文件 |
| `region FLASH/RAM exceeded` | 容量超限；缓冲、栈、堆配置过大 | 查 Map 文件定位大户；常量入 Flash；裁剪缓冲与栈 |
| ISR 向量名与启动文件不符 | 函数名拼错（如 `USART1_IRQHandler` 写成 `USART1_IRQn`） | 对照 `startup_*.s` 弱符号表逐字核对 |
| 栈顶/链接脚本符号缺失 | 分散加载/链接配置缺失 | 检查工程链接配置与栈大小定义 |

## 4. HardFault 定位流程

### 4.1 现场采集

进入异常处理后调试器暂停，读取：

- `PC`、`LR`、`SP`；`CFSR`（SCB->CFSR）、`HFSR`、`MMFAR`、`BFAR`
- Cortex-M 压栈帧顺序：`R0, R1, R2, R3, R12, LR, PC, xPSR`；由 SP 读出 PC 定位出错指令

### 4.2 CFSR 位含义

| 位 | 含义 | 典型成因 |
|---|---|---|
| IACCVIOL | 指令访问违例 | 函数指针野值；跳转地址非法；Thumb 位缺失 |
| DACCVIOL | 数据访问违例 | 空指针/野指针；访问未使能外设寄存器；数组越界写 |
| IBUSERR / PRECISERR / IMPRECISERR | 总线错误 | DMA 缓冲地址越界；外设时钟未开即访问；写只读位 |
| UNDEFINSTR | 未定义指令 | 栈踩坏；调用栈失衡 |
| INVSTATE | 非 Thumb 态 | 函数指针地址为偶数；链接异常 |
| NOCP | 协处理器非法访问 | FPU 未使能却执行浮点指令；编译浮点选项不符 |
| STKERR / UNSTKERR | 压栈/出栈错误 | 栈溢出，SP 越界 |

### 4.3 排查顺序

1. 栈溢出：局部大数组、深调用链、RTOS 任务栈不足；查 Map 与栈水位。
2. 空指针/未初始化：句柄、指针、回调表判空缺失。
3. 外设访问顺序：时钟使能先于寄存器访问；DMA 缓冲类型与地址正确。
4. 上下文错误：ISR 中长操作/阻塞调用；RTOS 中断优先级越界调 API。
5. 浮点：FPU 使能与编译选项一致。
6. 定位 PC 后对照源码反汇编确认触发行；禁止以「屏蔽异常」替代根因修复。

## 5. 高频运行故障排查树

### 5.1 串口无输出 / 乱码

1. 接线交叉、共地、电平匹配（3.3V TTL 与 RS232 区分）。
2. 时钟：`fPCLK` 与波特率复算一致；HSE 未起振回退 HSI 会导致频偏。
3. 引脚：模式、复用号与台账记录一致；调试器占用脚冲突排除。
4. 代码：初始化返回值检查；发送启动；回调重启接收；打印重定向未被优化。
5. 乱码优先查波特率不匹配，其次校验位/停止位一致、线缆干扰与共地。

### 5.2 DMA 不触发 / 数据不动

1. 外设 DMA 请求使能位；DMA 通道映射与台账核对项是否已销项。
2. 缓冲区指针、数据宽度、长度；启动函数是否调用。
3. DMA 中断使能与标志清除；DMA 控制器时钟使能。
4. 循环模式下缓冲长度 ≥ 最大单帧。

### 5.3 ADC 数据异常（恒零、满幅、跳变、漂移）

1. 通道号-引脚映射；引脚模式为模拟。
2. 参考源、增益、采样时间是否满足源阻抗；参考电压稳定性。
3. DMA 数组顺序与通道 Rank 顺序一致；类型宽度匹配。
4. 校准流程；信号超范围；滤波窗口过大带来滞后。
5. 电流采样先查模拟前端（偏置、增益、滤波），再查软件换算。

### 5.4 PWM 无波形 / 占空比不变化

1. 定时器时钟与分频复算；ARR ≥ CCR。
2. 引脚复用模式；`PWM_Start` 调用；高级定时器 MOE 主输出使能。
3. 刹车输入是否有效电平强制关断；死区是否过长。
4. 示波器接地弹簧短接实测，排除探头引线干扰误判。

### 5.5 SPI / I2C 通信失败

1. 接线、上拉（I2C）、片选、供电电平。
2. CPOL/CPHA、速率上限、器件地址（7bit）。
3. 超时错误处理与重试；总线锁死恢复；上电时序延时。
4. 从器件复位与使能状态。

### 5.6 中断进不去 / 反复进入

1. NVIC 使能与优先级分组；外设中断使能位。
2. ISR 函数名与启动文件向量一致；回调中是否重启接收/清除标志。
3. 标志位清除时机；重复进入多因标志未清。
4. RTOS：调用 API 的中断优先级不越界。

### 5.7 RTOS 异常（栈溢出、死锁、任务不调度）

1. 栈水位测量；栈大小估算与局部缓冲排查。
2. 互斥量获取顺序一致；ISR 不调阻塞 API；队列满有兜底。
3. 任务未让出 CPU（无延时/阻塞调用）；栈大小为 0；优先级配置。
4. 周期任务执行时间接近周期导致抖动。

### 5.8 电机/功率安全故障（辅助定位，不替代硬件保护）

1. 过流：先查采样链路硬件，再查软件阈值与采样同步点。
2. 桥臂直通：死区、互补逻辑、刹车响应、栅极驱动供电与米勒回路。
3. 环路振荡：先处理模拟补偿网络与采样滤波，控制增益按阶跃响应逐步整定。

## 6. 台账联动定位法

1. **节点对照**：出问题外设先打开台账对应节点，核对 `usage`、引脚、参数、TODO 项。
2. **双向差异表**：列出「台账记录值 vs 代码实际值 vs 实测值」三列，不一致处优先修。
3. **TODO 优先排查**：台账中未销项的 AF/IRQn/DMA 映射，是首次运行异常的高发点。
4. **变更回溯**：功能异常时先确认台账是否落后于原理图/实际接线；先更新台账再改代码。
5. **资源冲突反查**：台账引脚占用表交叉检查是否存在复用冲突或中断线冲突。

## 7. 观测手段建议

- 调试器：断点、监视窗口、外设寄存器视图（SVD）、反汇编对照 PC。
- 时序：逻辑分析仪解码 UART/SPI/I2C/CAN；示波器看 PWM、ADC 输入、电流纹波、栅极波形。
- 工程分析：Map 文件定位 RAM/Flash 大户；`.list` 查函数占用；RTOS 栈水位与线程列表。
- 软件可观测：关键状态枚举化、错误码固定格式日志；复位原因寄存器记录；最小系统法逐外设点亮验证。
