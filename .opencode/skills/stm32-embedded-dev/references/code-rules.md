## 1. 技术栈判定（S0 结论表）

| 维度 | 选项 | 默认与切换规则 |
|---|---|---|
| 固件库 | HAL / LL / 标准库 SPL | 默认 HAL；用户指定即切换函数风格，分层结构不变 |
| 系统 | 裸机主循环状态机 / FreeRTOS | 默认裸机；出现「任务、队列、调度、并发」需求时启用第 6 节 |
| 工程形式 | 新建模块 / 现有工程续写 | 现有工程走第 7 节；句柄与初始化复用不重写 |

## 2. 台账字段 → 代码位置同源映射表

| 台账字段（hardware.dts） | 代码落地位置 | 代码中承载方式 |
|---|---|---|
| 实例 label（`uart2`） | 句柄 `huart2`；模块前缀 `uart2_xxx()` | 命名对齐，不另起名 |
| `current-speed = <115200>` | `huartX.Init.BaudRate` | 集中宏 `BSP_UART2_BAUDRATE` |
| 引脚组 `uart2_tx_pa2`（pin/af） | GPIO 初始化结构体端口/引脚/模式/复用 | AF 未核实 → `#define BSP_UART2_TX_AF n /* TODO: RM 复用表核对 */` |
| `channel@2`（label `ch_vin`） | ADC 通道号配置、采集数组下标顺序 | 通道枚举宏 `ADC_CH_VIN`，顺序与台账 label 列表一致 |
| `frequency-hz = <20000>`（PWM） | TIM PSC/ARR 复算后填入；CCR 范围 | 复算过程写入注释；常量入宏 |
| `dmas` / `dma-names` | DMA 句柄配置 + 外设 Init 关联 | 通道号 TODO 集中在 `bsp_conf.h` |
| `interrupts = <IRQn pri>` | NVIC 使能/优先级；ISR 函数名对齐启动文件向量 | 优先级宏集中定义 |
| 器件子节点 `reg = <0x48>` | 总线读写地址参数 | 器件地址宏 `I2C_ADDR_TEMP` |
| 安全节点 `brake_bkin` / `en_power` | GPIO 初始化 + 故障处理函数 | 有效电平、安全态与台账 `polarity`/`safe-state` 一致 |

## 3. 分层落点速查（架构细则见 architecture.md）

> 架构确认流程、层级表、目录树、依赖红线 D1–D6、文件归属决策表统一查 `architecture.md`；本节仅给代码落点与命名规则。

| 层 | 目录 | 代码职责 | 落点要点 |
|---|---|---|---|
| APP | `APP/` | `app_init` 三步编排、调度线程、循环线程、业务任务 | 只调用不实现器件细节；顺序：外设使能→设备初始化→任务注册 |
| MID | `MID/` | 调度器、设备管理器、解释层高级 API、日志、错误码 | 跨模块公共机制；不含具体器件时序 |
| BSP/MODULES | `BSP/MODULES/` | 具体器件驱动（屏/传感器/计量芯片/按键编码器） | 句柄结构体 + 对外接口；向下调用 PERIPHERAL；规范见 module-convention.md |
| BSP/PERIPHERAL | `BSP/PERIPHERAL/` | 片上外设封装（SPI/I2C/ADC/PWM/UART/TIME/GPIO） | 一个外设实例一个模块；封装初始化/收发/启停；向下调 LL/HAL |
| 集中配置 | `bsp_conf.h`（或层头文件） | 引脚/通道/缓冲长度/超时/地址/AF 宏 | 禁止函数体散落魔法数 |

命名规则：

- PERIPHERAL：`bsp_<外设>.c/.h`（`bsp_spi.c`、`bsp_adc.c`），接口 `<外设>_<动作>`（`spi_init`、`adc_init_dma`）。
- MODULES：`bsp_<器件缩写>.c/.h`（`bsp_st7789v.c`、`bsp_sc8701.c`），接口 `<器件>_<动作>`（`st7789v_init`）。
- MID：`task_sched`、`dev_manager`、`service_<域>`；APP 固定 `app.c/app.h`。
- 依赖方向：APP → MID → MODULES → PERIPHERAL → LL/HAL；禁止反向包含与循环依赖。
- 目录落点红线：文件路径写全相对目录（`BSP/MODULES/bsp_sc8701.c`）；业务 `.c/.h` 禁止放工程根目录；根目录仅 `hardware.dts`、`framework.md` 与构建工程；骨架缺失时先列入新建清单（architecture.md 3.3），不把文件随手丢进根目录或只读库目录。

## 4. 通用编码规范（编号规则，违反即返工）

| 编号 | 规则 |
|---|---|
| R1 | 命名：模块前缀 + 动作（`adc1_read_vin_mv()`）；静态函数 `static`；宏大写下划线 |
| R2 | 返回值：HAL 调用检查 `HAL_OK`；自定义模块枚举错误码；等待接口必带 `timeout_ms`，超时返回错误，禁止裸 `while(1)` 死等 |
| R3 | 参数宏化：速率、缓冲长度、超时、通道号、滤波窗口全部 `#define`，函数体无字面量常数 |
| R4 | 注释：文件头写职责与对应台账节点；函数注释含功能/参数/返回；待核实行 `/* TODO: 手册核对点 + 查阅位置 */` |
| R5 | 常量入 Flash：查表、协议字串 `const`；中断与主循环共享变量 `volatile` |
| R6 | 边界安全：数组下标判断；`snprintf` 替代 `sprintf`；指针解引用前判空；句柄先初始化成功再使用 |
| R7 | 回调复用：多实例共用 HAL 回调时先判 `Instance` 再分支；ISR/回调内仅置标志、搬运缓冲、提交任务 |
| R8 | 头文件：`.h` 只放声明与宏；定义收敛到单个 `.c`；跨模块句柄 `extern` 声明，禁止重复定义 |
| R9 | 文件编码 UTF-8；注释中文；日志/协议常量集中定义 |

## 5. 外设要点速查表

### 5.1 GPIO

| 项 | 规则 |
|---|---|
| 模式 | ADC 脚 = `Analog`；复用功能 = `AF` 模式；I2C = 开漏；输出 = 推挽；输入按键 = 上下拉/浮空按台账 `pull` |
| 输出封装 | `xxx_set(on/off)` 内部处理有效电平翻转，逻辑不散落多处 |
| EXTI | 触发沿对齐台账 `trigger`；回调先判引脚；只置标志/提交任务 |
| 未用脚 | 按台账 `disabled` 建议配模拟输入或下拉，不悬空 |
| 易错 | 复用脚再被 GPIO 函数读写；EXTI 线号跨引脚冲突；调试脚（PA13/PA14）被挪用 |

### 5.2 USART

| 模式 | 适用 | 骨架要点 |
|---|---|---|
| 轮询发送 | 低频日志/命令 | `HAL_UART_Transmit` 带超时；中断内禁止调用 |
| 中断单字节接收 | 简单定长协议 | `HAL_UART_Receive_IT`；回调重启接收；解析在主循环/任务 |
| DMA 循环 + 空闲中断 | 不定长帧、高吞吐 | `HAL_UARTEx_ReceiveToIdle_DMA`；RxEvent 回调取 `Size` 写入环形缓冲；解析状态机不在回调内跑 |
| 易错点 | — | 波特率按 `field-map.md` 公式复算；RX 时钟使能；环形缓冲 head/tail 取模；帧头/长度/校验与残帧丢弃处理 |

### 5.3 ADC

| 模式 | 适用 | 骨架要点 |
|---|---|---|
| 单次轮询 | 低频单点 | Start → `PollForConversion` → 读数 → Stop |
| 规则组扫描 + DMA 循环 | 多通道周期采集 | 通道顺序 = DMA 数组下标顺序；`uint16_t` 匹配 12 位；完成/半完成双回调 |
| 注入组触发 | 电机相电流、PWM 同步采样 | 触发源配置对齐台账同步备注；换算系数（偏置+增益）集中宏 |
| 通用要点 | — | 采样时间满足源阻抗；带校准系列上电先校准；参考源对齐台账；滤波标注延迟；易错：通道-引脚错位、宽度不匹配、缓冲缺 `volatile` |

### 5.4 定时器（中断 / PWM / 输入捕获）

| 项 | 规则 |
|---|---|
| 频率公式 | `f = fTIMCLK / ((PSC+1)×(ARR+1))`；APB 预分频 ≠1 时 `fTIMCLK = 2×PCLK`；中心对齐周期约 `2×ARR`；复算过程写注释 |
| 定时中断 | `HAL_TIM_PeriodElapsedCallback` 先判 `Instance`；回调内不跑长逻辑 |
| PWM | 先 `HAL_TIM_PWM_Start`；运行期 `__HAL_TIM_SET_COMPARE` 更新占空比；`ARR ≥ CCR` |
| 高级定时器（TIM1/8） | MOE 主输出使能；刹车极性、死区为安全项，对齐台账刹车节点；故障动作 = 停 PWM + 关使能 |
| 输入捕获 | 测频：两次上升沿差值 + 溢出计数；测脉宽：双边沿；单位换算独立函数 |
| 易错 | PSC/ARR 忘 +1；APB 倍频漏算；无 MOE 导致无波形；刹车被有效电平拉住 |

### 5.5 SPI

| 项 | 规则 |
|---|---|
| 配置 | CPOL/CPHA 以从机手册为准（台账字段）；数据宽度；SCLK ≤ 从机上限 |
| 片选 | 软件 GPIO 管理：拉低 → 收发 → 拉高；每次检查返回值与错误标志 |
| 批量 | 评估 DMA；收发缓冲长度对齐；易错：模式配反、片选保持不足、字宽不匹配 |

### 5.6 I2C

| 项 | 规则 |
|---|---|
| 速率 | 100k/400k 对齐台账；上拉与电容属硬件，台账已备注 |
| 封装 | `dev_read_reg(addr, reg, buf, len)` / `dev_write_reg(...)`；7bit 地址（按所用 HAL 版本约定核对 R/W 处理） |
| 健壮性 | 超时返回错误码；总线忙/仲裁失败重试或上报；禁止死等；上电时序延时对齐台账 note |

### 5.7 CAN / FDCAN

| 项 | 规则 |
|---|---|
| 参数 | 位速率、采样点对齐台账且全总线一致；过滤器按接收 ID 配置（标准/扩展、列表/掩码） |
| 收发 | 发送带超时；接收回调/接收任务解析帧；校验 DLC 与 ID |
| 边界 | 收发器、终端电阻、共地为硬件；代码不替代硬件保护设计 |

### 5.8 DMA

| 项 | 规则 |
|---|---|
| 方向 | 外设→内存（ADC/RX）；内存→外设（TX/DAC）；内存地址递增、外设地址固定 |
| 宽度 | 外设数据宽度 = 数组元素类型（字节流 `uint8_t`；ADC `uint16_t`） |
| 模式 | 单次（传完重启）/ 循环（连续采集）；缓冲长度 ≥ 单次最大量 |
| 易错 | 通道/请求号映射（F1 固定；F4/G4/H7 有 DMAMUX 须查 RM）；缓冲缺 `volatile`；中断使能遗漏 |

### 5.9 NVIC

| 项 | 规则 |
|---|---|
| 一致性 | 分组方式与工程 `HAL_NVIC_SetPriorityGrouping` 一致；ISR 函数名逐字对齐 `startup_*.s` 弱符号 |
| 优先级 | 台账建议优先级落地；RTOS 中调用 API 的中断优先级数值不越 `configMAX_SYSCALL_INTERRUPT_PRIORITY` |
| 标志 | 退出 ISR 前正确清标志，防重复进入 |

## 6. FreeRTOS 可选层

### 6.1 机制选择表

| 需求 | 机制 | 要点 |
|---|---|---|
| 周期节拍任务 | `vTaskDelayUntil` | 相位稳定，替代 `vTaskDelay` |
| ISR → 任务事件 | 任务通知 / 队列 / 信号量（`...FromISR`） | 末尾 `portYIELD_FROM_ISR`；ISR 不用非 ISR API |
| 共享资源互斥 | 互斥量 `xSemaphoreCreateMutex` | 带优先级反转保护；临界区不含阻塞调用 |
| 多事件等待 | 事件组 `xEventGroupWaitBits` | 位掩码管理 |

### 6.2 约束表

| 编号 | 约束 |
|---|---|
| RT1 | 栈大小 = 局部变量峰值 + 调用链深度 + 异常压栈余量 ×1.5；上线用 `uxTaskGetStackHighWaterMark` 校准 |
| RT2 | 优先级：数值越大越高；任务内禁止阻塞式 HAL 长等待 |
| RT3 | 队列满/获取失败必须有兜底；互斥量获取顺序全代码统一 |
| RT4 | 开启栈溢出钩子；静态/动态分配方式与工程配置一致 |
| RT5 | 任务通知/队列传递数据副本时生命周期清晰，不返回栈内指针 |

## 7. 现有工程最小改动规则（强制）

| 步骤 | 动作要求 | 证据输出 |
|---|---|---|
| M1 通读 | 通读初始化、句柄定义、模块命名、头文件包含、现有台账 | S0 复用资源清单（文件:对象名） |
| M2 只追加 | 新功能归入新 `.c/.h` 或现有模块末尾；不改 `MX_xxx_Init`、不重构签名、不动已验证时钟/引脚 | 最小改动说明表逐行登记 |
| M3 标注插入点 | 每段代码给文件路径与插入位置（如「`bsp_adc.c` 末尾追加」「`main()` 中 `MX_ADC1_Init()` 之后」） | 代码块前标注 `【文件:位置】` |
| M4 必要修改说明 | 必须改现有行时登记「文件\|位置\|原值\|新值\|原因」；能用新增封装规避则不修改 | 改动表不得出现无理由修改 |
| M5 复用优先 | 现有句柄、宏、延时/打印工具直接引用，不重复定义同义设施 | 复用清单与代码引用一致 |
| M6 台账先行 | 新增硬件资源先登记台账片段，再写代码；代码参数回指台账字段 | 模板 B 第 2 节先于第 3 节 |
| M7 新模块挂接 | 新 MODULES/PERIPHERAL 模块按 module-convention.md M-DEV 步骤完成句柄与接口；初始化按 architecture.md 第 6 节三步法挂入 `app_init`；注册（设备管理器/调度器）同步完成 | framework.md 依赖矩阵与任务表同步更新 |
