## 4. 二级：参数复算项与公式

| 编号 | 参数 | 公式 / 判据 | 记录位置 |
|---|---|---|---|
| Q1 | 串口波特率误差 | 过采样16：`USARTDIV = fPCLK/(16×Baud)`；误差按 DS 限值（常见 ≤±2%） | 台账 note + 代码宏注释 |
| Q2 | PWM/定时频率 | `f = fTIMCLK/((PSC+1)×(ARR+1))`；占空比 `CCR/(ARR+1)`；中心对齐周期约 `2×ARR` | 台账 frequency-hz + 代码复算注释 |
| Q3 | ADC 转换时间 | `Tconv = 采样周期 + 转换周期(查 DS)`；多通道节拍 ≥ 通道数 × Tconv + 处理余量；不超 `fADC_max` | 台账 note + 代码采样节拍 |
| Q4 | SPI 速率 | SCLK ≤ 从机上限；CPOL/CPHA 与从机时序图一致 | 台账 frequency-hz/cpol/cpha |
| Q5 | I2C 速率 | 100k/400k 档位；上拉阻值与总线电容匹配（硬件侧） | 台账 clock-frequency-hz |
| Q6 | CAN | 速率 + 采样点全总线一致；位段和为标称位时间 | 台账 bus-speed-bps/sample-point-permille |
| Q7 | 外部时序 | 上电稳定等待、复位脉宽、片选建立保持时间对齐器件手册 | 台账 note |

## 5. 三级：健壮性与安全项

| 编号 | 核对项 |
|---|---|
| S1 | 初始化返回值已检查；失败有回退，不继续访问句柄 |
| S2 | 等待/收发接口带超时退出，无裸死等 |
| S3 | ISR/回调内无阻塞发送、打印、长循环；仅置标志/搬运/提交任务 |
| S4 | 缓冲边界判断；索引回绕正确；共享缓冲 `volatile` |
| S5 | 数组/字符串操作有长度上限；指针解引用前判空 |
| S6 | RTOS：队列/信号量创建成功再用；互斥量不跨阻塞持有；栈经水位估算；ISR 不越界调 API |
| S7 | 故障动作链落地：故障检测 → 停 PWM/断输出 → 关使能，方向与台账 `safe-state` 一致 |
| S8 | 看门狗喂狗周期在窗口内；主循环卡死可被复位（如启用） |
| S9 | 未用引脚有处理配置（模拟输入/上下拉），不悬空 |
| S10 | 改动仅限追加与指定位置；已验证逻辑未被重写（对照 code-rules 第 7 节） |
| S11 | 分层依赖单向：APP/MID 不向下实现细节；MODULES 不反向引用 APP；无循环 include；新模块符合 module-convention.md M-DEV 步骤 |
| S12 | framework.md：T1 三章齐全；T2 增量清单完整；耗时列仅含 `[预估]` 值，实测列留空待回填，无编造实测数字 |
| S13 | 软件架构五维度齐全：执行范式（前后台/事件驱动/抢占多任务）、调度模式、设计模式、模块化要点、共享数据；范式与调度机制相互匹配无冲突 |

## 6. 手册查阅指引

| 台账/代码内容 | 查阅位置 | 查什么 |
|---|---|---|
| 外设实例数量与编号 | RM 外设章节开头；DS 功能概览 | USART/ADC/TIM/SPI/I2C 数量 |
