# C 内存与数组错误参考

## Overview

为嵌入式/硬件 C 开发提供内存类错误的完整知识库与标准回答套路。核心前提：**C 语言不做数组边界检查**，越界、野指针、堆破坏均属于未定义行为（UB），不必然崩溃，表现为"偶现 bug、变量被篡改、free 时才炸"等难以复现的现象。

## 回答工作流（Workflow）

无论用户要"总结""排查""面试考点"还是"做题"，统一按此流程组织答案：

1. **判定错误类别** —— 从用户描述的现象/代码定位到具体类别（见 reference 的《错误现象对照表》）。
2. **讲清根因** —— 一句话点明这是哪种 UB、C 为什么不拦它（无边界检查、指针退化、内存布局等）。
3. **给出最小复现代码** —— 附可运行的错误示例 + 安全写法（成对出现）。
4. **说明后果与触发时机** —— 尤其点出"延迟报错"：如堆越界常在 free 时才崩。
5. **给出检测/排查手段** —— ASAN、Valgrind、编译警告。
6. **列出安全编码守则** —— 对应的防错规范。
7. **（可选）收尾** —— 按需生成背诵版/Word 文档/练习题。

## 常用示例速查（无需读 reference 即可回答的原子事实）

**数组越界**
```c
char buf[16];  buf[16] = 'a';   // 栈越界，下标0~15合法
int *p = malloc(4*sizeof(int)); p[4]=1;  // 堆越界，破坏堆管理头，free时才崩
char s[8]; strcpy(s,"123456789");  // strcpy不检查长度
```

**指针类**
```c
int *p;       // 未初始化野指针
int *q=malloc(4); free(q);   // q成为悬垂指针，free后未置NULL
*q=10;        // 悬垂/野指针解引用 = UB
*(a+5);       // 尾后指针 a+5 只能比较不能解引用
a[-1]=1;      // 下标负数向前越界
```

**堆配套错误**
```c
free(p); free(p);  // double free
free(arr);         // arr是栈数组，free非malloc地址 → 崩溃
int *p=malloc(10); // 想存10个int只分10字节，应为10*sizeof(int)
```

**sizeof 数组坑**
```c
void f(char buf[]){ int n=sizeof(buf); }  // buf退化为指针，sizeof==8(64位)，非数组长度
char b[16]; sizeof(b);  // 定义作用域内才为数组总字节
```

**其他 UB**
```c
int a=INT_MAX; a=a+1;   // 有符号溢出=UB；unsigned溢出是定义好的模2^n
char *p="hello"; p[0]='H';  // 修改只读字符串字面量→段错误；char p[]="hello"可改
int* test(){ int a[10]; return a; }  // 返回栈地址→悬垂指针
```
