# 调试、外设寄存器和内存分析

## 调试目标

调试程序默认按修改时间在以下目录寻找最新的 ELF / AXF / EXE / OUT：

```text
build/
Debug/
Release/
out/
工程根目录
```

也可在配置 → 调试里手动指定调试程序。

- **PE `.exe`**：使用普通 gdb。
- **ARM ELF/AXF**：复用烧录配置里的 OpenOCD / pyOCD 参数启动 GDB server，再用 `arm-none-eabi-gdb` 连接并 `load`。
- gdb 路径可填 `arm-none-eabi-gdb.exe`，也可填其 `bin` 目录；配置页有 **自动检测**。
- 不要用 MinGW gdb 调 ARM 目标，否则可能出现 `error 193` / `not a valid Win32 application`。

## 基本操作

| 操作 | 快捷键 |
|---|---|
| 启动 / 继续 | `F5` |
| 运行中暂停 | `F5` 或浮层按钮 |
| 停止 | `Shift+F5` |
| 下一步 | `F10` |
| 单步进入 | `F11` |
| 跳出 | `Shift+F11` |
| 切换断点 | `F9` 或点击行号左侧 |
| 回到当前执行行 | 调试浮层最左侧准心 |
| 跳转定义 / 引用 | `F12` / `Shift+F12` |

- 首次启动会先停在 `main`，并自动打开入口文件。
- 目标运行中浮层主按钮显示暂停图案，状态显示“运行中”。
- 暂停后自动打开并高亮当前执行行；每次新停止都会重新定位，即使上次停在同一行。
- 断点按 `(路径, 行号)` 保存；gdb 报 `No compiled code for line N` 时对应断点会被移除并提示。
- 调试日志在输出面板 **调试输出** 页，底部输入框可以发送任意 gdb 命令。

## 调试侧栏

### 变量

- Live Watch，可添加变量或表达式并自动刷新。
- 没有调用栈面板。

### 寄存器

- 只读 CPU 寄存器表。
- 通过 gdb `echo` 标记解析。

### 外设

使用 SVD 结构树：

```text
ADC1
├─ ISR
│  ├─ JQOVF [10:10]
│  ├─ AWD3 [9:9]
│  └─ ...
├─ CR
└─ DR
```

- 点击外设名称展开寄存器，点击寄存器名称或左侧箭头展开位域。
- 显示位域名称、`[msb:lsb]` 和提取值。
- 过滤框按外设、寄存器名、地址或说明过滤，匹配时自动展开。
- 目标暂停时，寄存器和位域右侧的 **改** 可以写入：
  - 寄存器按 SVD `size` 截断。
  - 位域使用读-改-写。
  - 目标运行时会拒绝写入。
- 没有 SVD 时可用 **导入 SVD** 把 `.svd` 复制到工程根目录，或 **重新扫描**。
- 每次最多读取 160 个寄存器，用 `x/1xw` 读取实时值；读取失败显示“无法读取”。
- 自动刷新开启且目标暂停时约每 1.5 秒更新。
- 限制：固定 32 位读取；64 位寄存器只显示低 32 位；不展开 `dim` / `cluster` / `enumeratedValues`。

## 外设数据来源

1. 工程内 `.svd`
2. 工程根目录 `.pack` / `.pdsc` 内的 SVD
3. 已安装 Keil DFP 的 `SVD/*.svd`
4. 头文件 `*_BASE` / `*_ADDR` / `*_ADDRESS` 宏回退

SVD 支持 peripheral 和 register 级 `derivedFrom`，以及 `bitOffset`+`bitWidth`、`lsb`+`msb`、`bitRange`。

## 内存可视化

构建输出面板右侧：

- `.data` / `.bss` 全局变量（最多 200 个，展示前 14 个）
- `_estack` / `_Min_Stack_Size` 栈区
- `ucHeap` / `.heap` FreeRTOS 堆区
- 调试暂停且 SP 可用时估算当前栈使用

缓存按 ELF 路径/修改时间刷新；面板内 **刷新** 强制重读。

## 动态监测（watchpoint）

右侧 **检测** 在有调试会话时打开“动态监测”：

- 添加 `watch`（写）、`rwatch`（读）、`awatch`（读写）硬件 watchpoint。
- GDB 优先使用硬件比较器，Cortex-M 通常 2–4 个；可能退化为软件 watchpoint（界面标记“软件”）。
- 命中后目标暂停，记录本机时间、旧值 → 新值、源码位置和 `bt 6` 调用栈。
- 勾选 **调试时自动启动动态监测** 后，启动调试会打开面板，并在临时 `main` 断点暂停后重新启用保存的 watchpoint。
- 表达式和历史在停止调试后保留。

## 已知限制

- 调试是基础 gdb 控制台，不是完整 IDE 调试前端；没有调用栈面板和独立内存编辑面板。
- OpenOCD / pyOCD 的参数来自烧录配置；烧录工具选“自定义命令”时，ARM 调试前要改成 OpenOCD 或 pyOCD。
- 内存布局只写入工程配置，不改写链接脚本。
